## 💻 Como Sincronizar com o seu Computador (PC)

### 1. Clonar pela primeira vez no seu computador:
```bash
git clone https://github.com/lucavalheiro1-web/my-project.git
cd my-project
```

### 2. Puxar alterações feitas aqui para o seu PC:
```bash
git pull
```

### 3. Enviar alterações do seu PC para cá:
```bash
git add .
git commit -m "Minhas atualizações"
git push
```
